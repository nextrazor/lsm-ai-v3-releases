# LSM.AI v3 — Windows releases

Public Windows x64 installers and update files for LSM.AI v3.

[Download the latest version](https://github.com/nextrazor/lsm-ai-v3-releases/releases/latest)

Install a release from this repository once to enable in-app update checks.
Updates are offered inside the app; installation restarts it.

Pilot installers are unsigned and may trigger Windows SmartScreen warnings.
macOS installers are distributed separately and do not use this update feed.

This repository contains distribution files only. Corporate documents, credentials,
and application source code are not published here.

There are no published installers until the first release is verified and published.
